# Abhi Online Center V3
React + Express + MongoDB management system.
Modules: Login, Dashboard, New Entry/Billing, Customers, Services, Payments, Expenses, Stock, Reports and CSV export.

## Local
Copy `.env.example` to `.env`, configure MongoDB Atlas, then:
`npm install`
`npm run dev`
Open `http://localhost:5173`.

## Render
Build: `npm install`
Start: `npm start`
Set PORT, MONGODB_URI, JWT_SECRET, ADMIN_USERNAME and ADMIN_PASSWORD.
